# Lucky Grab

태블릿/모바일 브라우저에서 바로 실행할 수 있는 단일 화면 럭키볼 뽑기 웹앱입니다.

## 변경 사항
- 집게 이동은 **좌우만 지원**합니다.
- 조이스틱은 **좌우 드래그 전용**으로 수정되었습니다.
- 조이스틱 비주얼은 아케이드 컨트롤러 형태로 구성되었습니다.
- 공 개수는 **20개**입니다.
- 성공 시 **100가지 명언** 중 하나가 랜덤으로 표시됩니다.
- 전체 UI는 **밝은 회색 톤**으로 조정되었습니다.

## 파일 구성
- `index.html` : 전체 화면 구조
- `style.css` : 스타일
- `app.js` : 게임 로직

## 실행 방법
그대로 GitHub 저장소 루트에 업로드한 뒤 GitHub Pages를 활성화하면 됩니다.

## PC 테스트 키
- `← / →` 또는 `A / D` : 좌우 이동
- `Space` : 잡기
- `C` : 가운데 정렬
- `R` : 리셋
